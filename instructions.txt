### **Section 4: Differentiable Plasticity & Three-Factor Learning Implementation**
Develop a custom PyTorch layer class (e.g., `NeuromodulatedLinear`) that handles weight changes during the forward pass.

**A. Hebbian Trace Management:**
*   For every connection $W_{ij}$, maintain a hidden Hebbian trace $E_{ij}$ (Eligibility Trace).
*   **Trace Update:** $E_{t} = (1 - \eta_{decay})E_{t-1} + \eta_{trace}(Pre_i \times Post_j)$.
*   **Three-Factor Weight Update:** During the simulation, adjust the active weights using the Meta-Agent's global signal: 
    $W_{active} = W_{baseline} + (Hormone_{signal} \times E_{t})$.

**B. Dynamic Hyperparameter Modulation:**
Create a mapping function within the `Local Worker` that updates the following at each timestep:
1.  **Learning Rate ($\alpha$):** $\alpha_{t} = \alpha_{base} \times DA_{concentration}$.
2.  **Softmax Temperature ($\tau$):** $\tau_{t} = \tau_{base} \times (1 / NA_{concentration})$. 
    *   *Result:* As NA increases, the agent's action selection becomes more random (Exploration).
3.  **Discount Factor ($\gamma$):** $\gamma_{t} = \gamma_{base} \times \sigma(5HT)$.
    *   *Result:* High Serotonin makes the agent value long-term survival over immediate reward.

*   **The "Switch" (Unexpected Uncertainty):** At step 500, suddenly set Arm 0 to $(\mu=0)$ and Arm 4 to $(\mu=10)$. 
*   **Hormonal Trigger:** The Meta-Agent must detect the sudden drop in expected reward. This must trigger a **Noradrenaline (NA) spike**, which increases the **Exploration Temperature ($\beta$)**.
*   **Baseline Comparison:** Compare against a standard Epsilon-Greedy agent with a static $\epsilon=0.1$.
*   **Success Metric:** Log **Adaptation Latency** (number of steps to discover the new optimal Arm 4).

### **Section 6: Experiment 2 - High-Stakes Foraging (5-HT Test)**
Implement a risk-assessment task to test harm aversion through digital Serotonin.
*   **Environment Setup:** A choice between two Markovian states:
    1.  **Safe Source:** 100% chance of $+5$ reward.
    2.  **Risky Source:** 90% chance of $+50$ reward, 10% chance of "Death" (Immediate $-500$ penalty and reset total score to 0).
*   **Mathematical Trap:** The Expected Value (EV) of the Risky Source is higher $(0.9 \times 50 = 45)$, so a standard RL agent will repeatedly choose it and "die."
*   **Hormonal Trigger:** Upon the first "Death," the Meta-Agent must trigger a **Serotonin (5-HT) spike**. This must modulate the **Discount Factor ($\gamma$)** and inhibit the Dopaminergic response to the $+50$ reward.
*   **Success Metric:** Log the **Survival Rate** (Cumulative steps without a "Death" reset) and total accumulated reward over 5,000 steps.
